# Ainur Karimov · CV

[Сайт](https://ainureg.github.io/cv/) · [Русская версия](https://ainureg.github.io/cv/ru/)

## Что редактировать

**`content.json` — общий источник информации для сайта и PDF.** Здесь находятся профиль, контакты, компании, опыт, проекты, публикация, выступления, образование, обучение, математические достижения и ссылка на сертификаты. Русские переводы редактируются рядом с английскими.

Английские пункты опыта и выступлений используются в обоих форматах. Подробные кейсы и схемы выводятся на сайте. Скачиваемое резюме — простой английский PDF на одной странице A4; в него также включены обучение, достижения и ссылка на сертификаты.

```text
content.json       данные резюме
src/               исходники сайта, PDF-шаблон, изображения и шрифты
scripts/           сборка и проверка актуальности
tests/            проверки общей информации и одностраничного PDF
docs/             инструкции для двух архивных версий Twenty Seconds
build/            результат сборки; не хранится в Git
```

## Собрать локально

Нужны Python 3.13+ и инструменты для PDF. Python-зависимостей нет.

```bash
sudo apt-get install texlive-latex-base texlive-latex-recommended texlive-latex-extra texlive-fonts-recommended lmodern poppler-utils
python scripts/build.py
python scripts/check_bundle.py
python -m http.server 8000 --directory build/site
```

Просмотр: http://localhost:8000/ или http://localhost:8000/ru/. Старый адрес `/en/` сохранён.

- `build/site/` — готовый сайт; PDF находится в `build/site/assets/ainur-karimov-cv.pdf`.
- `build/resume/` — сгенерированный `.tex`, промежуточный PDF и логи. Для ручной правки скопируйте `.tex` в другую папку; следующая сборка его перезапишет.
- `build/site/build.json` — хеши исходных данных и файлов, по которым проверяется актуальность комплекта.

HTML, PDF и логи не нужно коммитить. Для проверки кода: `python -m unittest discover -s tests -v`.

## Оформление

`src/page.html` — шаблон сайта, `src/styles.css` — стили, `src/app.js` — интерактивность. `src/resume.tex.template` задаёт простой PDF. Изображения, официальные логотипы и локальные шрифты находятся в `src/assets/`; поясняющие схемы кейсов — в `src/visuals/`. Лицензия шрифта: `src/assets/Inter-LICENSE.txt`.

## Публикация и актуальность

После push в `main` GitHub Actions запускает тесты, собирает сайт и PDF из одной версии JSON и публикует готовый комплект в `gh-pages`. Сборка проверяет ровно одну страницу A4 и отсутствие переполнения. При ошибке предыдущий сайт остаётся опубликованным. Размер шрифта не уменьшается автоматически.

PDF создаётся при сборке, а посетитель скачивает готовый файл: серверный LaTeX на GitHub Pages не запускается. GitHub Pages настроен на ветку `gh-pages`, корень `/`.

## Архивные резюме

Ветки `archive/twenty-seconds-original` и `archive/twenty-seconds` сохраняют исходную версию до сайта и поздний вариант со сборкой из свежего JSON. Их исходники отделены от текущего сайта. [Инструкции по просмотру и разовой сборке](docs/TWENTY_SECONDS.md).
